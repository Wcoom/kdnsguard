# P6 查询轨迹

方案 §17.3 要求「100/1000/10000 条**可重放、经脱敏**的查询轨迹」。

**脱敏在这里是具体的**：轨迹里只有公开知名域名与保留 TLD（`.test`）下的合成
域名，**没有任何从设备上抓下来的真实查询名**。所以轨迹可以入库、可以给别人
复现，不会泄漏谁访问过什么。

| 文件 | 用途 |
|---|---|
| `real.txt` | 冷/热缓存：173 个不同真实域名 |
| `burst100.txt` | 同名爆发：同一域名 100 条，验收 single-flight（方案 §17.3） |
| `random1000.txt` | 缓存完全帮不上忙：1000 个各不相同的 `.test` 域名 |

重新生成（确定性，无随机源）：

```bash
python3 gen.py
```

⚠️ **不要用 `.test` 轨迹去对比用户态基线**：mihomo 对保留 TLD 本地短路
（实测 200 条 **0 包**出口），拿它对比等于让基线"免费赢"。包数对比要用
`real.txt`，并且**必须扣掉背景流量**（手机自己在持续解析，跑得久的一方会被
计进更多背景）。
